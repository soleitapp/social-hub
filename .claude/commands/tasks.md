Baja el plan a una lista de tareas: `specs/NNN-nombre/tasks.md`.

Spec (carpeta o número): $ARGUMENTS

## Pasos

1. Lee `spec.md` y `plan.md` de esa carpeta.
2. Copia `specs/_template/tasks.md` y completa una checklist ordenada. Cada tarea es **pequeña**, deja el repo compilando y
   lleva su criterio de verificación entre paréntesis.
3. Última tarea siempre: verificar contra los criterios de aceptación y reportar lo que no se pudo ver en pantalla.
4. Si el cambio son varias features, propón un commit por feature y marca en qué tarea se hace cada uno.

## Reglas

- No implementes.
- Orden: primero lo que otras tareas necesitan (datos, utilidades), después lo visible.
